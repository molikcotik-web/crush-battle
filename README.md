# 🔫 Strike Zone: FPS

CS/Standoff-подібний шутер від першої особи з реальною 3D-графікою (Three.js/WebGL), ботами з AI, економікою, магазином зброї та системою прогресу. Один файл — `index.html`, працює просто в браузері, без збірки та бекенду.

## ▶️ Грати онлайн

Після публікації на GitHub Pages (інструкція нижче) гра буде доступна за посиланням:

```
https://ВАШ_НІК.github.io/НАЗВА_РЕПОЗИТОРІЮ/
```

## 🚀 Як опублікувати на GitHub Pages

1. Створіть новий репозиторій на [github.com/new](https://github.com/new)
2. Завантажте `index.html` (і за бажання цей `README.md`) у репозиторій — можна просто перетягнути файл через веб-інтерфейс GitHub («Add file» → «Upload files»)
3. Перейдіть у **Settings → Pages**
4. У розділі **Source** оберіть гілку `main` (або `master`) і папку `/root`, натисніть **Save**
5. За хвилину-дві сайт стане доступним за посиланням виду `https://ВАШ_НІК.github.io/НАЗВА_РЕПОЗИТОРІЮ/`

Ніякого сервера, збірки чи бекенду не потрібно — це статичний HTML-файл, GitHub Pages віддає його напряму.

### Альтернатива через git (командний рядок)


## 🎮 Керування

**ПК:**
- `WASD` — рух
- `Space` — стрибок
- `Shift` — спринт (не можна стріляти на бігу)
- `Ctrl` — присід (точніша стрільба)
- Миша — огляд, ЛКМ — вогонь, ПКМ (з AWP) — оптичний приціл
- `R` — перезарядка, `G` — граната, `B` — магазин, `1-4` — вибір зброї, `Esc` — пауза

**Телефон:** ліва половина екрана — джойстик руху (до упору = спринт), права — огляд, кнопки внизу — вогонь / стрибок / присід / перезарядка / граната / магазин.

## ✨ Можливості

- Справжня 3D-графіка на WebGL (Three.js) — текстуровані стіни, динамічне освітлення, об'ємні моделі ботів і зброї
- 4 види зброї (Deagle, AK-47, M4A1, AWP з оптикою) з індивідуальним балансом
- Боти з AI: патрулюють мапу, переслідують, ухиляються боком у бою, тікають при низькому HP
- Економіка та магазин у стилі CS (броня, гранати, зброя за категоріями)
- Гранати з area-уроном, динамічним світлом вибуху та струсом камери
- Мапа з 4 тематичними зонами (метал, дерево/мішки, бетон, пісок) і власним патрульним маршрутом
- Система прогресу: рівні, розблокування зброї за вбивства, статистика — зберігається в браузері (`localStorage`)
- Головне меню у стилі Standoff з превʼю агента, який тримає обрану зброю
- Складність (Легко / Нормально / Складно), гучність звуку — все процедурне, без аудіофайлів

## 🛠️ Технології

Чистий HTML/CSS/JavaScript + [Three.js](https://threejs.org/) (завантажується з CDN). Жодних збірок, npm чи бекенду.
